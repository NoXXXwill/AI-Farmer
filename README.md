# AI-Farmer
Humans and AI unite to achieve maximum results together.

## Project idea

The core idea of this project is to launch an AI assistant for daily tasks with zero prior experience.
It starts from defining basic principles, rules, and templates, and evolves toward autonomous work and independent task execution.

## Team documentation rules

Repository process rules:

1. Every new achievement must be logged in `WINS.md`.
2. Every decision must be documented as a separate file in `docs/decisions/`.
3. Every progress update must be reflected in `CHANGELOG.md` or `PROGRESS.md`.
