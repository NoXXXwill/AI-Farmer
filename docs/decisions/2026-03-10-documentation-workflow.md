# Decision: Documentation workflow policy

- **Date:** 2026-03-10
- **Status:** Accepted

## Context
Команді потрібна проста й однозначна система, яка не дозволить втрачати досягнення, рішення та прогрес.

## Decision
Прийнято правило:

1. Кожне нове досягнення записується у `WINS.md`.
2. Кожне рішення оформлюється окремим файлом у `docs/decisions/`.
3. Кожен прогрес фіксується через оновлення `CHANGELOG.md` або `PROGRESS.md`.

## Consequences
- Зростає прозорість змін у репозиторії.
- Команді легше відстежувати історію рішень.
- Зменшується ризик втрати контексту про виконану роботу.
